 <h2 id="modo-de-usar">ℹ️ Modo de Usar</h2>

 Com base numa relação de proporção, você digitará três valores e ao apertar no botão "Calcular", ele te dará a resposta do valor desconhecido.

 Caso um dos três valores não forem preenchidos, o valor desconhecido dará como "Inválido".

 Essa calculadora também calcula números decimais!
